# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting when it is enabled for this repository:

1. Go to the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the issue, the affected version, and steps to reproduce it.

If GitHub's private reporting is not enabled, submit your report privately through [Progress Software's vulnerability reporting policy](https://www.progress.com/trust-center/vulnerability-reporting-policy). Do not disclose vulnerabilities publicly.

Reports submitted through GitHub's private reporting are visible only to the maintainers. We will review your report, keep you informed of progress, and publish a security advisory once a fix is available.
